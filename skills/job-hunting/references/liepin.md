# 猎聘 操作知识包

来源：真实会话实测（2026-11-03）。选择器失效时按 SKILL.md 自我修复规程更新本文件并刷新 `verified_at`。

## 登录态自检

- 已登录时首页显示「你好，<姓氏>先生/女士」样式的问候。

## 搜索的坑（与 Boss 最大的差异）

- **搜索 URL 直达会被重定向回首页**：`https://www.liepin.com/s/?key=<词>&city=<市>` 打开后跳回 home，参数丢失。
- 正确做法：在**首页搜索框**输入关键词后回车：

```js
await page.fill("@<搜索框ref>", "智能体");
await page.keyboard.press("Enter");
await page.waitForTimeout(6000);
```

- **结果页和详情页依次开在新标签页**：回车后搜索结果出现在新 Page（如 p2）；点岗位后职位详情又开新 Page（如 p3）。
  每一步之后都要检查 tabs 并切换：

```js
const tabs = await task.tabs();
console.log(tabs.map(t => ({ label: t.label, url: t.url, active: t.active })));
const page = task.page("p2"); // 或 p3
```

## 城市筛选

- 默认结果是全国的，需要点城市 chip 里的目标城市。
- 裸 `text="广州"` 会匹配多处导致歧义报错；用精确 li 匹配：

```js
await page.click('loc=css:li:text-is("广州")', { label: "筛选广州城市" });
```

## 筛选条件落地（F2 第 2 步用）

- **活跃度**：猎聘岗位卡片常带 HR 活跃时间文案（"刚刚在线/今日活跃/3日内活跃"等），低于画像⑯档位跳过；有筛选控件则优先点选。
- **公司规模**：搜索页筛选区「公司规模」档位（20人以下 … 10000人以上），按画像⑰下限勾选组合档位。
- 注意：猎聘筛选面板改动会触发**重新搜索并可能再开新 tab**，操作后先 `task.tabs()` 确认当前页。

## 「已沟通识别」（硬性排除：只投未沟通过的）

**⚠️ 猎聘没有可靠的"已沟通"按钮状态词**——实测教训：详情页「继续聊」是**常驻按钮，点过之后文案不变**，不能当判据。唯一可靠来源是**消息中心会话列表**：

- ⚠️ **重复招呼高发点（两次实测踩坑）**：点击「继续聊」后系统会**自动附带平台预设话术**（如"你好，我想应聘贵司…期盼回复！"）——这条自动话术本身就构成一次打招呼。因此：**只要岗位进入过沟通窗口（哪怕一个字没手打），下次必须跳过**；判断一律以 build-contacted-roster.js 的消息中心名单为准。

- **主判据（已实测定稿）＝官方投递账本**：`https://c.liepin.com/job/record/apply`「我的投递」页（tabpanel 标题带总数，如"我的投递 28"）。每条 list_item 含 岗位链接(URL 里有数字 jobId)/薪资/要求/**公司名**/行业规模/状态+时间戳——直接就是天然 roster。
  - ⚠️ IM 域 `d.liepin.com/chat` 会被重定向回 c.liepin.com 首页，**不要用**；首页侧栏也没有可点的消息中心链接。
  - build-contacted-roster.js 对该页跑 evaluate 抽取 → 落盘 contacted-roster.json。
  - 投递阶段：候选公司命中名单 → 跳过，记"未投原因：已沟通(名单)"。
- 同公司不同岗位也算已沟通（同一 HR 收件箱，重复招呼一眼假）——默认按**公司名**匹配，用户明说"按岗位区分"才放宽。
- 名单拉取失败（页面结构不认识）→ 整个投递轮降级为 dry-run，先给用户看清单，不盲发。
- Boss直聘不受此限：其列表按钮有「立即沟通/继续聊」状态差异，仍按 boss-zhipin.md 判据。

## 打招呼 / 投递入口

- 详情页按钮：**「继续聊」**（区别于 Boss 的「立即沟通」）。
- 点击后打开聊天窗口；猎聘聊天输入框通常就是普通 textarea，可直接 `fill()` + 点发送按钮
  （Boss 的 contenteditable 陷阱在这里不存在，但仍以当次 snapshot 为准）。
- **发送成功判据**：消息出现在聊天窗口且带时间戳；状态"未读"表示等待对方查看。
- 注意：点「继续聊」时系统自动发一条默认话术（"你好，我想应聘贵…"），属正常。
- ⚠️ **自动话术即完整招呼**：这条预设文案已经表达了应聘意图，进入沟通窗口后**什么都不要再补**——不追加自我介绍、不发第二句。真人打招呼就一句。（实测翻车形态：自动话术 + "我擅长搭建智能体架构…" 二连发 = 机器人特征。）
- ⚠️ **dry-run 禁止点「继续聊」**：点击即触发自动招呼，等于偷跑。dry-run 只在列表卡片读信息。

## 通用建议

- 每步 `waitForTimeout(4000~6000)` 给 SPA 留渲染时间再 snapshot。
- 快照里优先使用 ref（@N）而非自造 CSS 选择器。
